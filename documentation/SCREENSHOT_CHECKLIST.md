# Evidence checklist

Capture and insert genuine screenshots after running the project in Docker Desktop. This environment did not have a running Docker daemon, so no container-build, browser-through-container, Docker Hub, or GitHub screenshots could be captured here.

1. `docker compose build` completing successfully for both images.
2. `docker compose ps` showing both containers healthy/running.
3. Browser at `http://localhost:3000` before submission.
4. Successful form submission showing the Flask greeting.
5. `docker compose images` showing both tagged images.
6. Docker Hub page showing both pushed repositories.
7. GitHub repository page showing the committed project.

Use the same screenshots in the report. Never substitute a typed command transcript for a screenshot.
